# `gridStrategy`

`gridStrategy` arranges children in uniform cells, filled left to right. Unlike
strip, it derives its whole tiling from the item count and the config rather
than from the space available, which is what makes the row count knowable before
anything is laid out.

Config, spans, and sizing a grid to its own rows.

```tsx
<Zone strategyId="grid" config={{ cols: 3, gap: 8, padding: 8 }} />
```

| Config | Meaning |
| --- | --- |
| `cols`, `rows` | fixed counts |
| `maxCols`, `maxRows` | caps for auto-balancing |
| `orientation` | `wide` / `tall` square the count; `fit` fits the container |
| `maxItems` | capacity cap — mutually exclusive with `maxCols`/`maxRows` |
| `gap`, `padding` | pixels |
| `resizable` | emit span seams |

<Grid />

Setting `cols` makes `maxCols`, `rows` and `orientation` dead config. That used
to be silent; grid now declares it through `configConflicts` and it surfaces as
a `layout` trace.

## Fitting the container

`wide` (the default) and `tall` auto-balance on the item count alone —
`ceil(sqrt(n))` columns and `floor(sqrt(n))` — which keeps the *grid* square
and says nothing about the container it is squaring inside. Ten items in a
container half again as tall as it is wide take four columns and three short
rows, and every cell is smaller than it had to be.

`orientation: 'fit'` picks the count that makes the *cells* biggest and
squarest for the container it is given, scoring a cell by its shorter side —
a 10×1 cell has the area of a 3×3 one and holds nothing. Reach for it whenever
the container is not roughly square, or changes shape. A set `cols` or `rows`
is an answer already given and still wins, and without a container `fit` falls
back to `wide`.

## Spans

A child can cover several cells through `placement.span` — **cell counts, not
pixels**:

```ts
store.patchPlacement(id, { span: { cols: 2, rows: 1 } });
```

`span` is kept separate from `size` so one key never means pixels under one
strategy and cells under another. A span wider than the grid clamps.

## Sizing the grid to its rows

A grid derives its whole tiling from the item count, the spans and the config —
without reading the container. `gridTiling` reports it, so a host can size the
grid itself:

```ts
const { cols, rows } = gridTiling(items, config);
const height = rows * ROW_H + gap * (rows - 1);
```

It lays nothing out and takes no container. Empty items tile to `0 × 0`, so the
height comes out zero rather than one empty row.
