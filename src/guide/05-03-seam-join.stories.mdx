# Seam join

A neighbour seam can end in a destroy rather than a clamp. Push it past a pane's
floor and keep pushing: the gesture arms, and releasing closes that pane.

```tsx
<Zone
  strategyId="strip"
  config={{ axis: 'x', resizeMode: 'neighbor', joinOnOvershoot: true }}
/>
```

`joinThreshold` is how many main-axis pixels past the floor that takes — 24 by
default.

<JoinOnOvershoot />

**Off by default, because the gesture deletes a pane with no confirmation
step.** It is ignored under `resizeMode: 'redistribute'`, which has no single
pane to name. Whichever pane's floor breaks is the one closed: the neighbour
when the seam is pushed toward it, the dragged pane when pushed the other way.

## The armed state is visible by default

While armed, both the pane and the seam carry `data-join-armed`, and
`styles.css` gives them a visible default — a hatch and a thickened seam, from
`currentColor`. **The point of no return cannot wait on consumer CSS.**
Restyle through the two selectors:

```css
[data-node][data-join-armed]::after { /* the pane about to close */ }
.windease-affordance-hit[data-join-armed] > [data-affordance]::after { /* the seam */ }
```

## Escape hatches

`Escape` cancels mid-drag, and a cancelled pointer never commits. From the
keyboard, arrow past the floor to arm and `Enter` to commit; `Escape` or arrowing
back cancels, and `End` jumps to `aria-valuemax` without ever destroying. Arming
is announced in a polite live region.

A pane locked with `lock: { destroy: true }` — **or holding any descendant that
is** — never arms; its seam still resizes to the floor. The destroy runs in one
transaction, so a host recording history per transaction gets one undo step.

## Headless

`trackJoin` is the whole decision: give it the affordance's `join` and `bounds`,
this move's delta, and the overshoot it returned last time.
`destroyBlockedBy(store, id)` is the lock check to pass it.
