# Nesting and recursion

Any node with a `container` capability hosts children, and a child may itself be
a container. There is no depth limit and no special recursive type.

```tsx
<Zone id="root" strategyId="strip" config={{ axis: 'x' }}>
  <Panel id="sidebar" />
  <Zone parentId="root" kind="group" strategyId="strip" config={{ axis: 'y' }}>
    <Panel id="editor" />
    <Panel id="terminal" />
  </Zone>
</Zone>
```

Each container runs its own strategy over its own children against its own
viewport. Strategies work unchanged at any depth via the `LayoutNode` adapter —
a strategy never knows how deep it is.

## Splitting without a split strategy

`store.split(id, input)` builds the nested strip groups a multi-pane layout
needs, as one transaction:

```ts
store.split(paneId, { axis: 'x', at: 0.5, id: newPaneId });
```

Split is a verb over the tree, not a strategy holding a tree of its own — which
is why registering a child, removing one and dragging one all just work.
`store.unsplit(groupId)` reverses it.
