# `stripStrategy`

Children share one axis and fill the cross axis. This is the workhorse — rows,
columns, docks, and every split a `store.split` builds.

```tsx
<Zone strategyId="strip" config={{ axis: 'x', gap: 8, padding: 8, fill: true }} />
```

| Config | Meaning |
| --- | --- |
| `axis` | `'x'` or `'y'` |
| `fill` | stretch to the container's main extent |
| `gap`, `padding` | pixels |
| `defaultItemSize` | main-axis extent for an item stating none |
| `maxItems` | capacity cap; the rest go to `unplaced` |
| `overflowMode` | `'squeeze'` (default), `'scroll'`, `'unplaced'` |

<HorizontalStrip />

`{ axis: 'y' }` is a column — strip covers both axes, so a stacked column is
this strategy rather than a separate one. The
[stack strategy](/?story=guide--02-layout--2-04-stack) is unrelated: it shows
one child at a time.

## Sizing

Strip honors `hints.minSize` as a floor, `hints.maxSize` as a ceiling, and
`placement.size` as an explicit pixel extent along the main axis. Siblings
without an explicit size share the remainder.

```ts
store.patchPlacement(id, { size: { w: 240 } });
```

It emits a gutter after every non-last child, so resize comes for free
([§4](/?story=guide--04-resize--4-01-affordances-and-seams)).
