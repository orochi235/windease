# Seam-join Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dragging a resize seam past its neighbor's floor arms a join; releasing there destroys the neighbor and the dragged pane takes its space.

**Architecture:** Strategies declare who dies at each end of an affordance's range (`Affordance.join`). A pure `trackJoin` derives overshoot by subtracting the extent the layout absorbed from the pointer travel the user asked for, and arms past a threshold. The React handle accumulates the travel, paints the armed state, and commits `store.unregisterNode` on pointerup. Same pure-core/thin-DOM-wrapper split as `insertionIndexByMidpoint` and `childRectsForContainer`.

**Tech Stack:** TypeScript, React 18, Vitest (headless + jsdom), Playwright over Ladle, Biome.

**Spec:** [`docs/superpowers/specs/2026-08-22-seam-join-design.md`](../specs/2026-08-22-seam-join-design.md)

## Two repo facts every remaining task needs

**`exactOptionalPropertyTypes` is on.** An optional property cannot be explicitly set to
`undefined`, so `{ join: maybeUndefined }` does not compile against `join?: AffordanceJoin`.
Spread it conditionally instead — `...(join ? { join } : {})` — which omits the key rather
than setting it undefined. Task 3 hit this; assume any optional field you assign from a
maybe-undefined expression needs the same treatment.

## API note for every task that seeds a store

`createNode` takes `parentId` and `placement` as **top-level** fields — there is no
`membership: { ... }` input — and `container` requires `{ strategyId, config }`; `{}` is not
valid. See `src/constructors.ts` (`CreateNodeInput`). Existing tests such as
`src/move.test.ts` show the convention.

```ts
import type { AffordanceJoin } from '../layout-types.js';
import type { NodeId } from '../node.js';

/** Main-axis pixels past the clamp before a seam arms, when a strategy names
 *  no threshold of its own. Half a default pane's floor is too far to reach by
 *  overshooting a deliberate drag, and near enough to reach on purpose. */
export const DEFAULT_JOIN_THRESHOLD = 24;

export interface TrackJoinInput {
  join: AffordanceJoin;
  /** Cumulative main-axis pointer travel since the gesture began. */
  requested: number;
  /** Main-axis extent the layout absorbed: `bounds.valueNow` now, less its
   *  value when the gesture began. */
  consumed: number;
  /** Whether this node may be destroyed. Injected rather than read from a
   *  store so the arithmetic stays pure and testable with plain numbers. */
  canDestroy: (id: NodeId) => boolean;
}

export interface JoinState {
  armed: boolean;
  /**
   * The node at the end of the range being pushed against. A candidate, not a
   * verdict: it is populated whenever the gesture has a direction, so read it
   * only together with `armed`.
   */
  candidateId?: NodeId;
  /** Signed distance past the clamp; zero while the seam is still moving. */
  overshoot: number;
}

/**
 * Whether a seam gesture has been pushed far enough past its clamp to destroy
 * something on release, and what.
 *
 * The seam stops moving but the pointer does not, and nothing else in the
 * system records the difference: `requested` keeps growing while `consumed`
 * freezes at the floor. The gap is the overshoot, and its sign picks which end
 * of the affordance's range the user is pressing against.
 *
 * @group Layout
 */
export function trackJoin(input: TrackJoinInput): JoinState {
  const overshoot = input.requested - input.consumed;
  const candidateId = overshoot > 0 ? input.join.atMax : overshoot < 0 ? input.join.atMin : undefined;
  if (candidateId === undefined) return { armed: false, overshoot };
  const armed = Math.abs(overshoot) > input.join.threshold && input.canDestroy(candidateId);
  return { armed, candidateId, overshoot };
}
```

```ts
/**
 * The first node in `id`'s subtree — `id` itself included — carrying
 * `lock.destroy`, or null when nothing does.
 *
 * Deliberately stricter than the store it guards: `unregisterNode` asserts the
 * lock on the id it is handed and then cascades with no further checks, so a
 * locked descendant dies silently. A gesture that offers to destroy a subtree
 * asks this first, and returns the blocker rather than a boolean so the
 * refusal can name which descendant refused.
 */
export function destroyBlockedBy(store: Store, id: NodeId): NodeId | null {
  const node = store.getNode(id);
  if (!node) return null;
  if (node.lock?.destroy === true) return id;
  for (const childId of node.container?.childOrder ?? []) {
    const blocker = destroyBlockedBy(store, childId);
    if (blocker !== null) return blocker;
  }
  return null;
}
```

/** The join a seam between `item` and `next` declares, or undefined when this
 *  container has not opted in. */
function joinFor(
  cfg: StripConfig,
  item: LayoutItem,
  next: LayoutItem | undefined,
): AffordanceJoin | undefined {
  if (!next) return undefined;
  if (cfg.resizeMode !== 'neighbor') return undefined;
  if (!(cfg.joinOnOvershoot ?? false)) return undefined;
  return {

    atMax: next.id as NodeId,
    threshold: cfg.joinThreshold ?? DEFAULT_JOIN_THRESHOLD,
  };
}

function seed(lockLeaf = false) {
  const store = new Store();
  store.registerNode(
    createNode({
      id: asNodeId('root'),

      },

        parentId: asNodeId('root'),
        placement: { size: { w: 200 } },
        hints: { minSize: { w: 80, h: 0 } },
        ...(lockLeaf && id === 'b' ? { lock: { destroy: true } } : {}),

function mount(store: Store) {
  return render(
    <WindeaseProvider store={store}>
      <Container id={asNodeId('root')} viewport={{ w: 600, h: 200 }} />

/** The seam between a and b. */
function seam(): HTMLElement {
  const el = document.querySelector('[data-affordance-hit="resize-x-a"]');
  if (!el) throw new Error('seam not rendered');
  return el as HTMLElement;
}

/** Drag the seam right by `dx`, in one move, without releasing. */
function dragBy(el: HTMLElement, dx: number) {
  fireEvent.pointerDown(el, { clientX: 0, clientY: 0, pointerId: 1 });
  fireEvent.pointerMove(el, { clientX: dx, clientY: 0, pointerId: 1 });
}

describe('seam-join gesture', () => {

  beforeEach(() => {
    store = seed();

    mount(store);

    dragBy(el, 145);

    fireEvent.keyDown(window, { key: 'Escape' });

### Joining panes

With `joinOnOvershoot`, pushing a seam past a pane's floor and holding it there arms a
join: releasing destroys that pane and its neighbor takes the space. Off by default,
and ignored unless `resizeMode: 'neighbor'`.

```ts
store.registerNode(createNode({
  id: asNodeId('root'),
  container: {
    strategyId: 'strip',
    config: { axis: 'x', resizeMode: 'neighbor', joinOnOvershoot: true, joinThreshold: 24 },
  },
}));
```

The armed pane carries `data-join-armed` and so does the seam; the stylesheet hatches one
and thickens the other, and you restyle by overriding those selectors. Escape cancels, and
the destroy is a single undo step.

A pane carrying `lock: { destroy: true }` — or holding any descendant that does — never
arms. The seam still resizes up to its floor.

By keyboard: arrow the seam past the floor, then `Enter` to commit or `Escape` to cancel.
`End` still means "go to the maximum" and never destroys.
